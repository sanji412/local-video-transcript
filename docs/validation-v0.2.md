- 通过实际 HTTP API 上传 60 秒 MP4，显式选择 `accurate`，约 15.57 秒完成。返回的历史记录原稿与编辑稿初始一致，模式及文件名保存正确。

- 查看“原始转写”确认只读；编辑稿与原稿分别展示，复制和导出始终使用编辑稿。

## 审查及限制

后端独立审查通过。前端最终审查发现三类可能丢稿的请求时序问题，补充六项回归测试后复审通过：未绑定文稿时编辑、旧 GET 覆盖新保存结果，以及延迟的初始恢复覆盖主动选择。

自动保存约在停止输入 700 毫秒后执行，失焦时尽快保存。保存失败或版本冲突会阻止直接切换，保留本地编辑并提供重试或导出；冲突不会自动覆盖其他窗口的新稿。页面有未保存内容时提供离开提示，但不承诺操作系统崩溃能保住尚未完成保存的最后按键。

历史数据库为用户数据目录下的 `history.sqlite3`，只长期保留文案和来源信息，不保存原音视频。旧版无法获取的浏览器内编辑稿不能凭空恢复。精确模式减少本次样本中的部分错误，仍需校对，未增加 OCR、在线转写或生成式纠错。
