# 0.4 批量提取、重复提醒与效率统计验证

日期：2026-11-02。设备：Apple M5、16 GB。功能与限制见 README。

## 自动化验证

`./scripts/check.sh`：178 个后端测试、75 个前端测试通过，Ruff、TypeScript、生产构建和 diff 空白检查通过。测试不下载模型、不访问抖音；TestClient 存在一条已有的依赖弃用提示。

覆盖批量分享文本解析与 20 条上限、串行处理与全局互斥、暂停/继续/停止、失败继续、重试、同批与历史重复、强制另存、回听音频生命周期、队列落盘及重启恢复、数据库迁移和有限非负耗时校验。前端覆盖预览、强制开关、刷新恢复、保存后再启动队列、保留当前编辑稿、重复提醒与耗时显示。

独立审查发现并修复了取消中途重启导致条目永久运行、局部识别展示旧全文耗时两个问题，均有回归测试。另补了保存失败回滚、换链接清除旧重复选择，以及字幕批量项显示“未调用模型”的测试。

## 真实模型与接口

使用已有约 60.07 秒的普通话测试视频，通过系统网络禁用配置运行本地模型：

| 模式 | 模型识别（含加载） | 流水线耗时 | 倍实时 |
| --- | ---: | ---: | ---: |
| 快速 turbo | 10.57 秒 | 10.83 秒 | 5.68 |
| 精确 large-v3 | 15.03 秒 | 15.16 秒 | 4.00 |

另通过独立工作台的上传接口运行真实快速模型：识别 7.30 秒、总处理 7.78 秒。任务与保存后的历史字段一致，保留回听音频可读取。速度受模型缓存、机器负载及内容影响，上述结果仅代表测试样本，不是性能承诺。

## 浏览器与数据

- 在独立数据目录中用受控工作进程验证四项队列：完成、重复跳过、失败、继续完成；实际观察了当前条完成后暂停及手动继续。队列展示总处理、模型识别、视频时长与倍实时，可手动打开结果。此队列验证不代表本轮已完成四条真实抖音下载。
- 桌面 1280 与窄屏 390 的页面内容宽度均等于视口，无横向溢出。
- 本地正式库启动后读取到 7 条文稿，先前 6 条文稿的原始全文与已有备份一致；升级后数据库已另存核对副本。本轮首次启动前备份因读取权限失败，未取得新的完整升级前快照，因此不宣称逐字段核对了本轮启动前的全部编辑内容。自动化迁移测试另验证旧数据与编辑内容保持。
- 真实模型结果、接口记录、数据库副本和页面截图保存在忽略的 `.local-data/v4-validation/`；独立审查记录保存在 `.superpowers/sdd/v4/`。

## 已知范围

仅保留最近一个批次，最多 20 项；服务重启后需手动继续。旧历史没有视频 ID 时，不同短链接可能无法判重。抖音获取仍受平台访问限制，失败可使用本地 MP4。旧文稿耗时不补猜，字幕直接提取不计为模型识别。
