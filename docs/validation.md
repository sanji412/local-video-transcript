## 真实环境及模型

- 设备：Apple M5、16 GB 内存 Mac。
- 运行环境：Python 3.12.14、Node.js 22.22.3、FFmpeg 9.0.1。
- 引擎：mlx-whisper 0.4.3，模型为 `mlx-community/whisper-large-v3-turbo`。
- 模型固定修订：`a4aaeec0636e6fef84abdcbe3544cb2bf7e9f6fb`。
- 约 1.6 GB 模型已实际下载，完成 MLX 加载及参数求值验证；下载与验证合计约 114.2 秒。
- 已验证的模型放在应用默认用户目录，当前机器启动后无需重复下载。
- 本次实测选定 turbo；没有下载 medium 做对比，不宣称两者速度或准确度的比较结论。

## 真实转写与离线验证

| 场景 | 结果及证据 |
| --- | --- |
| 本地中文 MP4，经 HTTP API 完整处理 | 使用系统中文语音生成 13.8395 秒测试视频，约 8.16 秒完成，输出 69 字符；人工检查测试句内容完整，原视频保留且临时目录删除 |
| 操作系统禁止网络后的转写 | 用 `sandbox-exec` 的 `deny network*` 策略运行独立工作进程，同一视频成功转写，约 3.54 秒；证明模型就绪后本地转写不依赖外网 |
| 离线进程内存 | `/usr/bin/time -l` 记录峰值 memory footprint 为 2,451,835,112 字节；此值包含该测试运行的内存占用，不代表所有视频的上限 |
| 静音 MP4 | 真实解码后明确提示没有有效语音，没有生成虚构文案 |
| 损坏 MP4 | 返回可读的文件读取错误，不误报为时长超限 |

上述耗时只代表当前设备与样本，包含模型首次加载和缓存差异，不能用来承诺所有 30 分钟视频的处理速度。

## 用户提供的抖音视频

- 分享链接：`https://v.douyin.com/YxDhnVDo_AU/`。
- 成功解析目标视频 ID：`7698325281026690331`，元数据显示时长 862.9 秒（约 14 分 23 秒）。
- yt-dlp 的标准路径遇到平台 Cookie 限制；匿名公开 Feed 信息接口实际返回与目标 ID 一致的视频信息，因此加入了经实测的补充获取路径。
- 补充路径不读取浏览器 Cookie、不使用账户登录；校验返回状态、目标 ID、时长、大小、域名和公网 DNS，再有界下载媒体。
- 经真实 API 跑通链接获取、完整音轨处理及本地转写：**66.17 秒，5,172 字符，来源为语音转写**，结束后临时目录删除。
- 转写稿保存在项目忽略目录的测试输出中，没有提交原视频、文案或带临时参数的媒体地址到 Git。
- 本次验证了这一条真实链接，尚未建立大样本下载成功率；平台或接口变化时仍可能失败，界面保留本地 MP4 导入入口。

该视频转写结果没有逐字人工校对，口语、人名和同音词仍可能识别错误；这不等同于逐字还原画面字幕。

## 界面、启动及恢复

- 浏览器实际打开生产服务，检查了窄屏布局、模型就绪和完成结果显示；桌面布局也做过截图检查。
- 实际编辑中文测试文稿并点击复制，界面显示“全文已复制”。另实际点击了真实视频文稿的 TXT 导出按钮，界面确认导出；导出内容与编辑稿一致由交互测试验证。
- 原始稿和编辑稿分别存储在任务结果与当前编辑状态中；重新连接时可恢复当前任务，并保留已编辑稿的导出机会。
- 一键脚本在默认用户目录下实际启动成功，网页和 API 同源提供，监听 `127.0.0.1:8765`；依赖缓存就绪后离线检查完成，没有重复下载模型。
- 已补回归：取消旧任务不能影响新任务；服务重启后重新连接会刷新令牌与任务；提交期间不能通过重新连接使界面卡住。
- 崩溃回归实际强杀 API 父进程，确认工作进程及后代退出，实例锁释放后新服务才可清理残留并接受任务。
- 独立代码审查发现的任务竞态、流式上传错误状态、连接恢复、崩溃残留和 Homebrew Node 路径问题均已修复并通过复审。

## 验证边界

完整字幕的优先选择及不完整字幕退回转写已通过自动化测试；本次真实抖音样本走的是语音转写，没有宣称已验证抖音可独立获取完整字幕的普遍可用性。

首版不包含 OCR、批量任务、云端转写或跨会话历史。模型、环境及具体依赖版本见锁文件，使用与启动方式见项目 README。
