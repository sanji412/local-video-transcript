# 完整稿与候选“不采用”

用户要求保留现有分段回听和编辑，在编辑稿与原始转写之间增加编辑后的完整稿，并为重识别候选增加“不采用”。

## 行为

- 三种视图依次为“编辑稿 / 完整稿 / 原始转写”，完整稿只读，直接展示当前编辑文本，包含尚在保存的修改，不另存一份副本。
- 完整稿沿用全文复制及 TXT 导出，原始转写继续不可修改；切换回编辑稿保留段落修改及现有保存队列。
- “不采用”只收起候选，不触发任何文稿 PATCH。采用成功和不采用都记住当前候选任务 ID，视图切换及当前标签页刷新后不再展示已处理候选。
- 只在 sessionStorage 中保存一个任务 ID，不保存正文；新的任务 ID 仍显示候选。存储不可用时保留内存中的选择。
- 采用结果的保存正在进行时禁用两个选择按钮；保存失败保留候选，并允许重试或不采用。
- 仅更新前端，不重启后端服务，不改动本地文稿和回听音频。
