# 分享文案自动命名

用户希望粘贴完整抖音分享内容后，直接用其中的视频标题命名本地文稿，免去逐条重命名。

采用本地文本解析：在已验证的单个视频链接之前取标题，清理开头的抖音分享编号、日期和口令，再去掉末尾话题标签。示例 `0.71 :1pm b@n.qR EHv:/ 07/18 学就完了，祝大家都是表达高手 # 表达 # 干货 https://v.douyin.com/BCVusZue21g/ ...` 得到 `学就完了，祝大家都是表达高手`。保留标题中的标点、数字、英文和表情，合并换行及重复空格，最长 200 字。

相比联网获取视频页面标题或用转写正文生成标题，直接解析分享内容无需额外请求，符合用户明确指定的标题来源。仅提供裸链接或清理后无标题时，仍使用“链接文案”；本地文件仍使用文件名。

API 在任务创建时解析标题，任务管理器保留到识别完成，再随文稿一次性写入现有数据库 title 字段。来源仍保存已验证的网址，正文不混入分享内容。手动重命名和版本控制保持原行为。

历史记录只保存了网址，无法从中恢复原分享标题，本次不批量猜测或覆盖旧标题。不新增联网请求、模型或数据库迁移。

验证覆盖用户示例、不同口令排列、多行、标签、纯链接、数字及英文标题、200 字上限，以及 API 到完成任务的持久化与搜索。
