# 下一版：本地历史、自动保存与精确识别

用户已确认此范围，并接受更长的识别等待时间。延续本地处理、30 分钟、500 MB、单任务和临时媒体清理约束。

## 历史与保存

SQLite 保存在应用用户数据目录中。成功提取后先可靠保存原始全文，再展示完成；原稿不可变，编辑稿独立保存。保存来源链接或文件名、标题、时间、识别模式及结果来源，不长期保存媒体。

历史支持搜索、打开、重命名和删除。编辑后约 700 毫秒自动保存，显示保存中、已保存及失败重试；切换文稿、开始新任务、删除和离开页面时保护未保存内容。使用修订号防止多窗口旧稿覆盖新稿。重启后可恢复最近文稿。

## 精确识别

保留现有 turbo 快速模式，新增完整 large-v3 本地精确模式，模型单独下载、校验并缓存，首次选择需明确准备状态。新用户操作默认精确模式；旧 API 默认快速模式以保持兼容。实际效果用相同音频对比，不承诺消除所有错字，不用生成式改写替代原始讲述。

## 验收

- 重启后历史及编辑稿仍在，原稿不被修改。
- 搜索、重命名、删除正常，保存失败可重试；并发编辑返回冲突，不静默覆盖。
- 切换文稿或新任务不会丢失待保存的文字，保存状态与实际持久化一致。
- 两种模式分别下载和使用本地模型，仍能断网转写；相同真实口播记录准确度观察和耗时。
- 原有取消、崩溃清理、文件限制和安全校验回归通过。
