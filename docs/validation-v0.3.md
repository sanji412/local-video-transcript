## 真实离线识别

沿用此前用户提供的 14 分 23 秒口播中的首 60 秒样本，不重新联网获取视频，不新增下载模型。使用系统禁止网络的独立进程运行：

- 完整识别：18.20 秒，34 段，358 字符。
- 第一段时间范围 0.0–2.6 秒，单独识别：1.27 秒。
- 实际 MLX 结果保留起止秒数，全文等于各段文字以换行拼接。
- 时间数据来自模型或完整字幕，没有根据字数猜测或强制重新对齐。

耗时只代表这一样本。局部识别可能得到相同结果，或仍有错字，因此采用前保留候选供用户决定，不承诺必然提升。

## 限制

- 旧文稿没有保存时间戳和音频，需重新导入原视频才能使用这两项功能；原编辑稿不受升级影响。
- 默认音频会在下一次全文提取或服务重启时清除，若需长期校对，应在导入时选择保留。
- 不做逐字强制对齐、字幕 OCR、批量提取及在线识别。保留有字幕时优先采用的原有策略，但仍提取本地音轨供回听。
- 仍采用原有本地串行任务和取消机制；局部候选只保留当前任务状态，新的识别任务可替换旧候选，已保存文稿保持不变。
